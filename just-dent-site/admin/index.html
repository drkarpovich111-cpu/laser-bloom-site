Як отримати ключ доступу?
  1. Увійдіть у GitHub під акаунтом drkarpovich111-cpu.
  2. Створіть Fine-grained token ↗.
  3. У Repository access виберіть Only select repositories → laser-bloom-site.
  4. У Repository permissions надайте Contents: Read and write. Встановіть строк дії ключа.
  5. Натисніть Generate token, скопіюйте його й вставте у поле вище. Збережіть ключ у менеджері паролів.

Ключ передається тільки GitHub і зберігається лише в пам’яті цієї вкладки. Після закриття або перезавантаження сторінки потрібно увійти знову. Не надсилайте його в чат.
